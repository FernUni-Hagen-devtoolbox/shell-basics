Shell Basics

In diesem Modul lernen Sie den grundlegenden Umgang mit Kommandozeilenwerkzeugen für Unix-artige Betriebssysteme, am Beispiel Linux. Wir stellen in diesem Kurs zunächst alle Lernressourcen so bereit, dass Sie sie von jedem Betriebssystem aus per Browser nutzen können. Sie können die erste Hälfte also auch ohne Probleme mit Windows oder MacOS bearbeiten.

Lernziele
  • Sie verstehen den Nutzen und die Vorteile der Linux-Kommandozeile
  • Sie können das Dateisystem navigieren
  • Sie können mit Dateien interagieren, können diese ausgeben, kopieren, usw.
  • Sie wissen, wie sie in unklaren Situationen Hilfe zu Befehlen und deren Optionen bekommen
  • Sie haben ein grundlegendes Verständnis von Benutzerrechten inklusive des sudo-Befehls
  • Sie können kleine Shell-Skripte zur Automatisierung schreiben

Das Modul besteht aus diversen Ressourcen, die Sie in den Reitern oberhalb dieses Textes finden. Starten Sie mit Motivation und Hintergrund für eine kurze theoretische Einführung.

Hinter den Reitern Lernpfad: Anfänger:innen und Lernpfad: Fortgeschrittene finden sie zwei Lernpfade durch dieses Modul. Auch wenn Sie bereits Vorerfahrungen mit der Shell-Nutzung haben, lohnt es sich in den Bereich für Anfänger:innen hineinzuschauen. Sollten Ihnen der Stoff dort zu leicht sein, können Sie jederzeit zum Bereich für Fortgeschrittene wechseln.
